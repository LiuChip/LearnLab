# 条件过滤 (WHERE)

在上一章中，我们学习了如何获取表中的所有数据。但是在实际应用中，我们通常只需要符合特定条件的数据。这时候就需要用到 `WHERE` 子句。

## 认识 WHERE 子句

`WHERE` 子句用于提取那些满足指定条件的记录。

### 语法

```sql
SELECT column1, column2, ...
FROM table_name
WHERE condition;
```

## 运算符

在 `WHERE` 子句中，你可以使用以下运算符：

- `=`: 等于
- `>`: 大于
- `<`: 小于
- `>=`: 大于等于
- `<=`: 小于等于
- `<>` 或 `!=`: 不等于

## 动手实验

让我们尝试过滤数据。假设我们要找出 `users` 表中所有年龄大于 18 岁的用户。

```sql
-- 找出年龄大于 18 岁的用户
SELECT * FROM users WHERE age > 18;
```
