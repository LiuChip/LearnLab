# LearnLab — 本地交互式实验浏览器

> 对标 VS Code：VS Code 是**代码编辑器 + 插件生态**，LearnLab 是**实验浏览器 + 插件生态**
> 2026-08-14 更新：从"云平台"重新定位为"本地小软件"
> 2026-09-01 更新：核心不提供云同步，只提供配置 JSON 导入/导出；插件按全局/当前实验包依赖加载，并受分层作用域和读写执行权限限制
> 设计边界：MySQL 课程计划由插件提供；核心中的两层 `.db` 只负责 LearnLab 自身状态，不是 MySQL 实验环境。当前新建持久 `.db` 默认是便携 JSON 格式。
>
> 本文介绍产品愿景；当前已交付能力与仍待冻结细节见[文档状态](STATUS.md)和[公开决策索引](DECISIONS.md)。

## 🎯 一句话定位

> **一个极简内核 + 插件生态的本地交互式实验浏览器。让不懂的人，通过别人给的实验包，也能自学学会一门知识。**

### 🎯 使命

**让知识可以通过"实验包"的方式，在人与人之间传递——不需要老师一对一、不需要昂贵的培训、不需要技术背景。**

### 👥 服务人群

| 人群 | 例子 | 角色 |
|:---|:---|:---:|
| **大学生** | 学 MySQL、学 Java、学高数、学物理 | **学习者**（也是未来的内容创作者） |
| **社会人群** | 转行程序员、自学设计的运营、想学数据分析的会计 | **学习者** |
| **教授/专家** | 数学教授、物理老师、资深工程师 | **内容创作者**（用 LabKit 制作实验包） |
| **机构/学校** | 大学课程组、培训机构、企业内部培训 | **源维护者**（搭建实验包源） |

**两大类人群同等重要**——没有学习者，实验包没人用；没有内容创作者，学习者没东西学。LearnLab 要做的，就是让这两类人之间的桥梁尽可能低门槛喵~！

### 📖 一个典型场景

以下是目标体验，尚非当前版本的操作教程：源安装、真实 MySQL 执行和自动判定仍未开放。

> 小张是一名会计，想学 SQL 分析公司数据。他的程序员朋友给他发了一个链接：
> **"装这个 LearnLab，然后加这个源，里面有 SQL 入门实验包。"**
>
> 小张下载安装 LearnLab → 设置里粘贴源链接 → 搜索"SQL 入门" → 点安装 → 开始做实验。
> 全程不需要知道 GitHub、不需要配环境、不需要懂编程概念。
>
> **一周后，小张学会了 SQL 基础，开始用查询分析公司的财务报表了。**

这就是 LearnLab 要实现的愿景喵~ (๑•̀ㅂ•́)و✧
