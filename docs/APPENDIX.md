## 附录 A：IDEA 价值评估与职业定位

> 来源：2026-08-27 讨论。

### IDEA 到影响力的鸿沟

IDEA 价值 ≠ 项目价值，中间隔着鸿沟：

IDEA 100分 → MVP 10分 → 能用 30分 → 有人用 50分 → star 70分 → 影响力 90分

现状：IDEA 阶段 100 分方向有了，实际产出 0 分。大三上最紧急 = 把 LearnLab 从设计文档变成能跑的 MVP。

### 大厂校招四个信号

| 信号 | 权重 | 现状 |
|:---|:---:|:---|
| 学历 | 30% | 南邮，认可度不错 |
| 实习 | 30% | **最大缺口** |
| 项目 | 20% | LearnLab 落地后补强 |
| 算法八股 | 20% | 持续刷 LC |

竞争不是"比谁学得多"，是"比谁有实习 + 深度项目 + 能讲清技术决策"。

### 差异化路径

- 大三上：LearnLab MVP 落地 + 找实习信息
- 大三上~寒假：冲日常实习
- 大三下：暑期实习申请（3-4 月投递）
- 暑假：暑期实习
- 大四上：秋招

大厂校招的差距是在大三下~暑假的实习申请季拉开的，不是靠现在多学几章教程拉开的。

### star 项目能否替代考研？

不能替代，但大幅改变局面。star 项目 = 强力简历信号 + 面试杀手锏，但大厂筛人先看学历和实习。LearnLab 让"考研和就业两条路都更宽"。

## 附录 C：相关项目与企业级参考

> 来源：8/27 企业级代码托管平台 IDEA 讨论（与 LearnLab 共享插件架构思想）。

### 企业级代码托管平台（另一 IDEA，暂缓）

- 架构：Gitea（现成 Git 服务端）+ SpringBoot（JWT/RBAC/任务派发/度量报表）+ VSCode 插件（登录/任务面板/行内评论气泡）+ WebSocket 推送
- 灵魂难点：行内评论锚定（commit_SHA + 路径 + 行号，行内容变 → 标 outdated）
- 参考：GitHub 官方 VSCode 插件 / JetBrains Space
- 安全原则：敏感逻辑必须放后端，前端壳防破解是伪命题
- MVP 四阶段：Gitea 部署 → 任务闭环 → 评论闭环 → 报表
- **与 LearnLab 的关联**：插件体系设计思想（极简内核 + 插件生态）一脉相承，Maven 的"核心 + 插件"理念也是同一来源
