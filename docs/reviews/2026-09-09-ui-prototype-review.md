# UI 原型优化与审查（2026-09-09）

范围：独立应用 `apps/ui-prototype`。对照本机 VSCode 的 Workbench、搜索视图和既有 UI 设计；保留上轮已修复的章节 hover、账户入口移除及 Menubar 占位决策。

## 视觉与交互调整

- 采用 48px Activity Bar、35px 标签/侧栏标题、24px 状态栏；工作台文字以 12–13px 为主，正文 15px，标题 26px。
- 缩减正文顶部留白、装饰卡片、模拟窗口圆点、重复进度和身份信息；代码保留独立横向滚动。
- 统一章节整行 hover/选中态、细边框和深浅主题。图标使用文字占位，正式图标继续后置。
- 主侧栏、辅助栏和底部面板可拖拽；窄窗口保留入口并以覆盖层展示侧栏，避免直接裁掉内容。
- 搜索按文档分组，可折叠结果、跳转到正文匹配行；替换框可折叠，选项只保留一份。
- 快速打开仅搜索原型已有章节。Menubar、原生窗口操作继续占位，不添加窗口排布菜单。

## 已修复问题

| 问题 | 后果 | 修复 |
| --- | --- | --- |
| 新通知导致全部计时器重新开始 | INFO 长时间不消失，进度条与实际消失时间不一致 | 每条通知按创建时间独立计算剩余时间；7 秒进度加 1 秒停留 |
| 通知 ID 按列表长度或实验 ID 生成 | 重复运行/关闭后新增出现重复 key | 使用单调递增的会话通知序号 |
| 未读数固定或盲目减一 | 刷新搜索不增加未读，删除已读通知误减其他未读 | 根据通知的 read 状态计算 |
| 切换/关闭标签不更新章节上下文 | 实验侧栏、右侧上下文、阅读进度与正文不一致 | 激活标签时同步章节归属，详情/空标签明确无当前文档 |
| 最后一个标签无法关闭 | 关闭按钮无效 | 正常关闭并显示可重新打开章节的空状态 |
| 所有教程按钮都打开第一个实验 | 条件过滤、连接章节打开错误实验 | 统一按当前文档声明的实验归属显示和打开 |
| 实验完成后强制切到底部历史 | 用户当前终端/输出被打断 | 完成只更新状态、历史和通知，不改变面板选择 |
| 实验历史为静态内容 | 运行次数和记录不会更新 | 会话内保存模拟运行记录，在实验和底部历史中共用 |
| 章节内容回退到第一章，状态栏固定 62% | 不同章节展示相同正文、进度不可信 | 每个示例章节独立内容及进度，实验不改变阅读百分比 |
| 搜索语料与显示正文不同 | 点击结果找不到匹配文本 | 从当前正文数据生成搜索语料并定位对应行 |
| 全部替换只发成功通知 | 内容未改却报告成功 | 内存替换、数量确认、一次撤销、非法正则阻止操作 |
| 替换正文后保留旧进度和滚动位置 | 修改后的章节仍显示已读 | 仅实际改动的文档重置；撤销恢复其原进度，不覆盖其他章节后来产生的阅读记录 |
| 搜索跳转后切换标签丢失位置 | 返回文档又跳回旧位置 | 显式保存搜索跳转位置，每个定位请求只执行一次 |
| 匹配数按行计数，全字模式忽略正则 | 数量错误，组合选项无效 | 逐个匹配计数，全字边界与正则共同生效 |
| 代码复制、目录列表等按钮无反馈 | 用户无法完成预期操作 | 实现复制和详情导航；没有真实服务的操作明确为未连接/未接入 |
| 隐藏 AI 侧栏丢失输入 | 草稿被卸载清空 | 会话状态保存草稿 |

## 验证与限制

- 模型回归覆盖标签/上下文/空状态、实验记录、阅读进度、通知生命周期/未读数、搜索/替换/撤销和正则组合。
- 假时钟覆盖连续 INFO、effect 重新订阅、取消计时及 warning/error 不自动关闭。
- 已通过：原型 22 项测试、TypeScript 检查、ESLint、独立生产构建、`git diff --check`。
- 扩展回归：主项目 72 项测试及全仓类型检查通过；3 个原有空测试套件跳过。测试命令仍输出 Vite CJS 弃用提示和 Node SQLite 实验性提示，没有失败。
- 浏览器检查覆盖 1440×900、1280×720、390×844 截图、深浅主题、实验 INFO 进度条与消失、真实内存替换及撤销、通知中心不切换终端、搜索后的标签位置恢复、AI 草稿保留、快速打开筛选、窄窗口选中文档后收起侧栏。
- 原型的数据库、真实运行时、插件宿主、AI 网络请求、菜单、设置、实验包切换仍未接入；本轮没有将原型合并到 desktop。
- 视图自由移动、预览/固定标签、脏状态确认、通知长期历史/堆叠策略和全局快捷键仍属于待冻结细节；本轮试用实现不视为正式冻结。
- 正则搜索目前在主线程对少量示例数据同步执行，未实现超时或复杂度限制；接入真实大实验包前需迁入可取消的后台任务，避免耗时正则阻塞界面。
