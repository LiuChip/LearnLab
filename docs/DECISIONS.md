# 公开设计决策索引

> 同步日期：2026-10-01。此表同步本地 `UNFREEZE.md` 的决定状态和最近 UI/实验交互修订，供公开仓库阅读。状态描述**设计确定程度**，不是功能完成度；已实现能力见[文档状态](STATUS.md)，实现顺序见[路线图](ROADMAP.md)。

`FROZEN` 表示方向和边界可作为验收依据；`PARTIAL` 表示主要行为已定但细节未定；`OPEN` 表示尚有多个方案；`DEFERRED` 表示当前阶段不做。进入实现前要为本任务写清输入、错误、清理和兼容行为，再更新该项与相应专题文档。

## 已确定的产品边界

- 本地桌面应用；单实例；核心不提供账号、服务器或云同步。
- 内容在实验包，学习环境与判定器由插件提供；插件加载按全局插件与当前包依赖闭包解析。缺失插件允许只读阅读。
- 插件权限分读、写、执行，按资源和当前包作用域求交；逻辑隔离不等于 OS 级沙箱。
- 章节阅读百分比只由章节决定，实验通过/失败不改变阅读进度；内容指纹变化才重置对应章节。
- 工作台使用单一 Editor Group、主/辅助侧栏、底部面板和独立通知；正式视觉参考 Workbench 的信息组织，不应复制品牌资产。
- 学习区、包进度、实验历史、配置各有归属；`.db` 是逻辑名称，新建持久文件当前使用便携 JSON driver。具体路径和未来迁移须与代码一致。
- 当前文件查找是 MVP 唯一开放范围。实验卡片“打开实验”只开标签；执行在标签内，关闭前清理本实验专用进程。
