## 🖼️ 布局设计

### 默认布局（两栏）

LearnLab 的默认状态是**简洁的两栏布局**——左侧目录树 + 右侧学习/实验区。底部终端不是默认组件，而是通过**插件启用**的。这样无论学什么学科，打开软件都是干净清爽的阅读体验喵~：

```
┌─────────────────┬──────────────────────────────────────────┐
│                 │  📄 2.3 创建表  │  🧪 实验2.3-1  │  +   │
│  左侧目录树      ├──────────────────────────────────────────┤
│                 │                                          │
│  📁 第2章       │   ## 2.3 创建表                          │
│    📂 2.1       │   CREATE TABLE 语句用于...               │
│    📂 2.2       │                                          │
│    📂 2.3       │   ┌──────────────────────────────────┐   │
│  📁 第3章       │   │ 📗 实验：创建 student 表          │   │
│    📂 3.1       │   │ 尝试次数: 0/5  [开始] [重置]      │   │
│    📂 3.2       │   └──────────────────────────────────┘   │
│                 │                                          │
│                 │   （学习内容 + 实验卡片占满整个区域）      │
│                 │                                          │
└─────────────────┴──────────────────────────────────────────┘
```

### 插件增强布局（启用终端插件后）

当安装了 **终端插件**（或某个实验包需要终端环境时自动提示启用），布局变为 VS Code 风格的三栏 + 多终端：

```
┌─────────────────┬──────────────────────────────────────────┐
│                 │  📄 2.3 创建表  │  🧪 实验2.3-1  │  +   │
│  左侧目录树      ├──────────────────────────────────────────┤
│                 │                                          │
│  📁 第2章       │   ## 2.3 创建表                          │
│    📂 2.1       │   CREATE TABLE 语句用于...               │
│    📂 2.2       │   ┌──────────────────────────────────┐   │
│    📂 2.3       │   │ 📗 实验：创建 student 表          │   │
│  📁 第3章       │   │ 尝试次数: 0/5  [开始] [重置]      │   │
│    📂 3.1       │   └──────────────────────────────────┘   │
│    📂 3.2       │                                          │
│                 ├──────────────────────────────────────────┤
│                 │  📟 终端① (mysql)  │  📟 终端② (bash) │
│                 │  $ mysql -u root -p                     │
│                 │  mysql> CREATE TABLE student (          │
│                 │      -> StudentID CHAR(12) PRIMARY KEY, │
│                 │      -> ...                             │
│                 │  -> );                                  │
│                 │                                          │
│                 │  [▶ 运行]  [↺ 重置环境]  [💡 提示]     │
│                 └──────────────────────────────────────────┘
```

### 两种模式对比

| 模式 | 适用场景 | 包含组件 |
|:---|:---|:---|
| **两栏模式（默认）** | 数学、物理、化学、文科等 | 目录树 + 学习区（讲解+实验卡片） |
| **增强模式（终端插件）** | 编程、计算机、数据库、Linux 等 | 目录树 + 学习区 + 终端面板 |

## 📑 学习区（多选项卡）

学习区是 LearnLab 的核心——**同一块区域，两种学习方式，自由切换**：

| 方式 | 内容形态 | 适合 |
|:---|:---|:---|
| **📖 阅读模式** | Markdown 文档 + 代码块 + LaTeX 公式 | 喜欢自己看、自己琢磨、按自己节奏来 |
| **🎬 视频模式** | 嵌入播放器，视频讲解 | 喜欢跟着老师走、听觉型学习 |

**两种模式可以同时开**——分屏左边放视频、右边放文档，或者看完视频立马切文档做实验，互不干扰喵~！

学习区支持多选项卡，类似于 VS Code 的编辑器标签页：

```
┌──────────────────────────────────────────────────────┐
│ 📄 2.3 创建表  │  🧪 实验2.3-1* │  📄 3.1 查询  │ + │
├──────────────────────────────────────────────────────┤
│                                                      │
│  当前选项卡内容（讲解/实验/文件/笔记等）              │
│                                                      │
└──────────────────────────────────────────────────────┘
```

**选项卡类型：**

| 图标 | 类型 | 说明 |
|:---:|:---|:---|
| 📄 | 讲解页 | 来自实验包 `content.md` 的章节文本 |
| 🎬 | 视频 | 实验包附带的视频讲解（支持常见格式，嵌入播放器） |
| 🧪 | 实验卡片 | 正在进行的实验，未完成时显示 `*` 标记 |
| 📝 | 笔记 | 用户自己写的 Markdown 笔记（可保存） |
| 📎 | 参考文件 | 实验包附带的示例代码、文档等参考文件 |
| 🔍 | 搜索结果 | 全文搜索的结果页 |

**交互行为：**
- 点击目录树中的章节 → 新标签页打开（或切换到已有标签页）
- 点击实验卡片的"开始" → 新标签页打开实验
- 标签页可拖拽排序
- 全局搜索打开“搜索结果”选项卡，搜索当前学习区内所有已登记实验包的章节正文；不跨学习区搜索
- 当前包缺少所需插件时，目录树和实验卡片显示“插件缺失/只读”提示，并提供查看依赖与授权入口
- 已激活插件可以注册面板、按钮、右键菜单和命令；注册内容必须随插件状态实时撤销
- 可配置少量全局快捷键（打开搜索、切换学习区、保存笔记、运行/停止实验）
- 标签页可拆分到新分组（分屏）
- 双击标签页空白处 → 新建笔记

## 📊 进度展示规则

- 章节阅读滚动到底部后标记“已读”；滚动位置仍然保存，方便断点续读。
- 学习区和实验包阅读百分比按实际发现的章节 Markdown 数量统计，不统计实验通过率。
- 实验数量和实验包的实验统计使用作者在 manifest 中声明的 `experiment_count`；扫描结果只用于发现、校验和跳转。
- 实验卡片独立显示状态和尝试次数；实验失败不会降低阅读百分比。
- 内容更新时按章节内容指纹判断：未修改的章节保留已读，修改的章节重置为 0%。
- 界面提供“标记已读”“标记已学习”快捷操作，适合用户自行整理非线性学习路径。

## 🎬 视频播放与笔记联动（基础功能）

视频播放是 LearnLab 的基础功能，但采用独立的视频选项卡（Electron 原生支持 `<video>` 标签，几乎零成本），而不是要求 Markdown 直接嵌入视频。高级视频功能通过插件扩展。

**基础功能（内核自带）：**
- 播放/暂停/进度条/音量/全屏
- 常见浏览器可播放格式（优先 mp4/webm；具体编码能力以当前平台为准）
- **视频独立选项卡**：实验包中的视频资源在视频选项卡中打开；Markdown 通过时间戳或 LearnLab 视频链接引导打开对应选项卡；
- **视频与笔记联动**：

```
笔记中写入时间戳链接：
  "在 [3:45] 处讲解了 synchronized 的原理"
  → 点击 [3:45] → 视频跳转到 3:45 位置播放 ✅

实验卡片的提示中也可以引用视频位置：
  "如果卡住了，看看视频 [7:20] 处的演示"
  → 点击 [7:20] → 视频跳转 ✅
```

**语法支持：** 在 Markdown 内容或笔记中，使用 `[MM:SS]` 或 `[H:MM:SS]` 格式即可自动识别为视频时间戳链接，点击后当前打开的视频（或章节关联的视频）跳转到对应时间点喵~！

**视频 ↔ 笔记双向联动：**
- **笔记 → 视频**：点击笔记中的 `[3:45]` → 视频跳转
- **视频 → 笔记**：观看视频时，在视频进度条上右键"在此处记笔记" → 自动创建一条笔记并插入时间戳

**插件增强（可选）：**
- 倍速预设（1.25x、1.5x、2x）
- 字幕/CC 支持（SRT 文件）
- 视频章节标记（类似 YouTube 章节）
- AI 视频摘要（自动生成文字概要）
- 画中画、投屏

## 🔎 全局搜索

全局搜索支持当前打开的学习区，MVP 搜索该学习区所有已登记实验包的章节 Markdown 正文，不跨学习区搜索。打开学习区后，后台逐步建立可重建索引；索引未完成时可以使用基础文本搜索，索引损坏时从文件重新生成。搜索结果以独立选项卡打开，显示实验包名称和章节路径，点击结果跳转到对应章节和匹配位置。实验卡片、笔记和其他资源搜索留到后续版本按需增加。

## 📝 笔记系统

学习不做笔记等于白学喵~！LearnLab 内置了**极简笔记功能**，让用户在学习过程中随时记录想法：

### 笔记类型

| 类型 | 创建方式 | 说明 |
|:---|:---|:---|
| **章节笔记** | 在学习内容页面点击"记笔记" | 自动关联当前章节，笔记与章节绑定 |
| **实验笔记** | 在实验卡片页面点击"记笔记" | 自动关联当前实验，包含实验卡片 ID |
| **自由笔记** | 双击标签页空白处 | 独立笔记，不关联任何内容 |
| **视频笔记** | 视频进度条右键"在此处记笔记" | 自动插入视频时间戳 `[3:45]`，点击跳转 |

### 笔记编辑器

```
┌──────────────────────────────────────────────┐
│ 📝 笔记 - 2.3 synchronized 理解               │
│                                              │
│  ## 理解 synchronized 的原理                  │
│                                              │
│  synchronized 加锁的是**对象**，不是代码块。   │
│  看视频 [3:45] 处的演示更清楚。                │
│                                              │
│  ```java                                     │
│  synchronized(this) {                        │
│      count++;                                │
│  }                                           │
│  ```                                         │
│                                              │
│  📎 关联章节：2.3 创建表                      │
│  🏷️ 标签：synchronized, 多线程, 锁           │
│                                              │
│  [💾 自动保存]  [📦 导出]  [🔗 复制链接]     │
└──────────────────────────────────────────────┘
```

**编辑器特性：**
- **Markdown 语法**（支持代码块、LaTeX 公式、图片、视频时间戳）
- **自动保存**（每 30 秒或切换标签页时保存，不用担心丢笔记）
- **时间戳链接**：输入 `[3:45]` 自动识别为视频跳转链接
- **标签系统**：给笔记打标签，方便检索

### 笔记存储与备份

```
笔记文件位置：
  ~/.learnlab/notes/
  ├── packages/                 # 按实验包组织的笔记
  │   └── mysql-intro/
  │       ├── ch2-3-synchronized.md
  │       └── ch3-1-query.md
  ├── free/                     # 自由笔记
  │   └── my-thoughts.md
  └── tags/                     # 标签索引（自动生成）

格式：纯 Markdown 文件（.md）
      → 可以用任何文本编辑器打开编辑
      → 可以用 Git 管理版本
      → 可以导出分享
```

**核心不内置云同步。** 笔记正文是普通 Markdown 文件，用户可自行复制、用 Git 管理或交给第三方插件处理同步；插件的认证、冲突和远端格式不属于 LearnLab 核心。

**为什么存为纯 Markdown 文件？** 因为：
- 不依赖 LearnLab 也能打开（任何文本编辑器）
- 可以用 Git 管理版本历史
- 方便导出/分享/迁移
- 实验包作者可以预置笔记模板

> 笔记的**元数据**（标题、标签、关联章节、创建时间）存 SQLite 便于检索，笔记的**正文**存 .md 文件保持人类可读。详见 [架构设计 · 存储策略](ARCHITECTURE.md#存储策略与目录规范)。

### 笔记与学习区的联动

```
┌──────────────────────────────────────────────────────┐
│  📄 2.3 创建表  │  🧪 实验2.3-1* │  📝 笔记  │  +   │
├──────────────────────────────────────────────────────┤
│                    ┌─────────────────────────┐       │
│  学习内容          │  笔记（分屏模式）        │       │
│                    │                         │       │
│  synchronized      │  ## 理解 synchronized   │       │
│  的原理是...       │  看视频 [3:45] 处的演示  │       │
│                    │  代码示例：             │       │
│                    │  synchronized(this) {}  │       │
│                    └─────────────────────────┘       │
└──────────────────────────────────────────────────────┘
```

**分屏学习模式：** 左侧学习内容 / 右侧笔记，边看边记，互不干扰。笔记中的视频时间戳点击后，如果当前有打开的视频，自动跳转到对应时间点喵~！

```

## 🔄 与 VS Code 的关系

增强模式很像 VS Code——这不是巧合，是**刻意的设计选择**：

| VS Code | LearnLab | 说明 |
|:---|:---|:---|
| 侧边栏（文件浏览器） | 左侧目录树 | 浏览文件/章节结构 |
| 编辑器标签页（多文件） | 学习区多选项卡 | 讲解/实验/笔记/参考 |
| 终端面板（多终端） | 插件增强 → 终端面板 | 运行 CLI 环境（需插件启用） |
| 编辑组分屏 | 学习区排列切换 | 分屏对比学习 |

**差异点**：VS Code 的"编辑器"里写代码，LearnLab 的"编辑器"里看讲解和做实验——功能不同，但窗口管理逻辑一致，用户零学习成本喵~ (๑•̀ㅂ•́)و✧
